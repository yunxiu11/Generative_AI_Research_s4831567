1. Storage and Accessibility<br>
Efficient file storage and organisation make research materials easier to locate, access, and share among team members. A clear folder structure also reduces the risk of losing files, using outdated versions, or duplicating research data.<br>
2.Specify which data types may require special access controls.Explain your reasons(2-3sentences)<br>
Personal and sensitive data, such as consent forms, interview transcripts, and participants’ information, require special access controls. This protects participants’ privacy and prevents unauthorised people from viewing or changing the data.<br>
3.why is it important to have a good naming convention<br>
A good naming convention makes files easier to find and understand. It also helps team members identify the correct version and prevents confusion between similar files.<br>
4.Under what scenarios, creating a new branch would be useful?<br>
Creating a new branch is useful when developing a new feature, fixing a bug, or testing new ideas. It allows you to make changes without affecting the main project. After the changes are tested, the branch can be merged back into the main branch.
